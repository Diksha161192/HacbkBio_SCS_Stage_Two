# HacbkBio_SCS_Stage_Two
HackBio-Single Cell Sequencing internship-October 2025 cohort-Stage two task
A certain bone marrow dataset was analysed using the scanpy tool and some other tools and libraries in python, as listed below:
1. scanpy
2. anndata
3. igraph
4. celltypist
5. decoupler
6. fa-2 modified
7. pandas
8. seaborn

Also this task walks you through the complete single cell RNA seq data analysis pipeline through steps enlisted below
1. Loading and preprocessing data
2. Quality control (QC)
3. Normalization and feature selection
4. Dimensionality reduction (PCA, UMAP)
5. Clustering
6. Marker gene detection and visualization
